# House Map Drag Pan Design

## Goal

Allow the enlarged house map to follow mouse and touch dragging while preserving house-link clicks and the existing zoom controls.

## Interaction

- The 2% overview remains fixed and does not pan.
- At zoom levels above 2%, pressing and dragging the map moves it directly with the pointer.
- Movement below 5 screen pixels remains a click. Movement at or above 5 pixels becomes a drag and suppresses the house-link navigation generated by that gesture.
- The map stops exactly where the pointer is released; there is no inertia or snapping.
- The cursor is `grab` while panning is available and `grabbing` while a gesture is active.
- Changing the zoom level or selected house pair recenters the map and clears the previous pan offset.

## Bounds

Pan is clamped in screen-space SVG units so the focused map cannot be dragged completely away. Horizontal movement is limited to 120 units in either direction and vertical movement to 72 units in either direction. These limits keep the focused route recoverable within the 287 by 180 map viewport while allowing useful inspection at every enlarged zoom level.

## Architecture

- `lib/house-map.mjs` owns pure pan normalization, clamping, and transform composition so boundary behavior can be tested without a browser.
- `components/site/HouseMapCard.mjs` owns pointer capture, the 5-pixel gesture threshold, click suppression, and reset behavior.
- `app/globals.css` owns pan affordances and disables the zoom transition during active dragging.

## Accessibility and Input

- Existing links and zoom buttons remain keyboard accessible.
- Pointer Events provide one implementation for mouse, trackpad-driven pointer input, pen, and touch.
- Native touch scrolling is disabled only on the SVG while map panning is available; the rest of the page keeps normal scrolling.

## Verification

- Unit tests cover clamping, overview behavior, and the composed transform.
- Static component tests confirm the map exposes its panning state and pointer handlers.
- A production build and local browser check confirm zoom, drag, release, click suppression, and house navigation behavior.
