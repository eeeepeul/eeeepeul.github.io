# 미발화하우스 실내 픽셀 타일맵 설계

## 목적

기존 Next.js 사이트의 현재 라우트와 기능을 변경하지 않고, 나중에 캐릭터와 NPC를 배치할 수 있는 실내용 픽셀 하우스 배경을 기존 `/second/` playfield의 배경 레이어로 통합한다. 1차 범위는 정적인 집 내부 배경과 유지보수 가능한 타일맵 데이터이며, 이동·NPC·DB·입력은 포함하지 않는다.

## 범위와 라우팅

- 통합 위치: `/second/`의 기존 playfield 배경
- 유지 대상: `/`, `/second/`, `/experience/` 및 기존 사이드바·네비게이션·캐릭터 추가 기능
- `/second/`의 기존 캐릭터 레이어 위에 타일맵을 배경으로 추가하며, 기존 레이아웃과 상호작용을 대체하지 않는다.
- 64×48 타일, 타일 기준 크기 16×16px
- 뷰포트 크기에 맞춰 전체 맵을 정수에 가까운 비율로 확대하고, 픽셀 렌더링을 유지한다.

## 맵 구성

맵 데이터는 렌더링과 분리된 `lib/house-interior-map.mjs`에 둔다. 데이터는 공통 `MAP_WIDTH`, `MAP_HEIGHT`, `TILE_SIZE`, 방 사각형, 문 개구부, 오브젝트 배치, 충돌 셀, 향후 스폰 지점을 노출한다.

방과 건물 범위:

- Main house: `x 6..57`, `y 4..40`
- Entrance projection: `x 24..39`, `y 41..47`
- Living Room: `x 20..42`, `y 14..30`
- Bedroom: `x 7..19`, `y 6..18`
- Study / Record Room: `x 43..56`, `y 6..18`
- Bathroom: `x 7..16`, `y 20..28`
- Kitchen + Dining: `x 43..56`, `y 21..35`
- Quiet Room / Rest Room: `x 7..19`, `y 30..39`
- Entry Hall: `x 20..42`, `y 31..40`
- Entrance: `x 25..38`, `y 41..47`

문 개구부는 거실과 각 인접 공간이 짧고 직접 연결되도록 데이터로 명시한다. 긴 복도는 만들지 않으며, 거실 아래쪽에는 현관홀로 연결되는 넓은 개구부를 둔다.

## 레이어 계약

렌더러는 다음 레이어를 순서대로 만든다.

1. `floor`: 방별 바닥 타일, 중앙 거실 러그
2. `walls`: 외곽선과 방 경계 벽 타일
3. `doors_windows`: 문짝, 문턱, 창문 표현
4. `furniture`: 침대, 협탁, 소파, 테이블, 싱크대, 식탁, 책상, 책장 등
5. `decor`: 조명, 화분, 매트, 간결한 장식
6. `collision`: 렌더링하지 않는 통과 불가 셀 집합
7. `spawn_points`: 렌더링하지 않는 향후 캐릭터 위치 정의

`collision`과 `spawn_points`는 시각 레이어와 별도의 데이터로 보존하여 다음 단계에서 캐릭터 이동 시스템이 직접 재사용할 수 있게 한다.

## 렌더링 접근

추가 라이브러리 없이 React의 정적 컴포넌트와 CSS Grid/absolute tile 요소로 구현한다. `HouseInteriorWorld`가 타일맵을 배경에 두고 기존 `FollowingCharacterWorld`를 독립된 전경 레이어로 유지한다. 64×48 타일 규모는 현재 브라우저에서 충분히 작으며, 레이어별 DOM 경계를 유지하면 테스트와 향후 상호작용이 쉽다.

각 타일은 `data-layer`, `data-tile-id`, `data-position` 속성을 가진다. 실제 PNG/SVG 타일셋이 준비되면 타일 ID와 CSS 변수 또는 asset map만 교체하고, 맵 데이터와 레이아웃 계약은 유지한다.

## 시각 스타일

- 바닥: `#f3f0e7` 계열의 아이보리와 밝은 회색
- 벽/외곽선: 짙은 블루 계열
- 포인트: 선명한 블루와 코랄/레드
- 보조: 회청색
- 오브젝트: 픽셀 모서리와 제한된 색상 수의 아이콘형 도형
- 외부 정원·연못·숲·마당 표현 없음

CSS는 `.house-interior-page`와 하위 클래스에만 한정해 추가한다. 기존 전역 레이아웃 및 기존 라우트의 스타일 규칙을 변경하지 않는다.

## 검증 기준

- 맵 상수가 정확히 64×48 및 16px로 노출된다.
- 모든 요구 방 범위가 데이터에 존재한다.
- 모든 요구 연결부가 문/개구부 데이터에 존재한다.
- 레이어 목록과 렌더 순서가 고정된다.
- 충돌 셀과 스폰 지점이 시각 레이어와 분리되어 있다.
- 기존 테스트가 모두 통과하고 정적 빌드가 성공한다.
- `/second/`가 기존 패널·캐릭터 기능을 유지한 채 실내 타일맵을 배경으로 표시한다.

## 다음 단계에서 하지 않는 것

캐릭터 이동, NPC AI, 키보드/포인터 입력, DB 저장, 카메라 추적, 네트워크 동기화, 외부 타일셋 다운로드는 후속 작업으로 남긴다.
